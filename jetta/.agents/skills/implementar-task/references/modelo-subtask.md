# Modelo de subtask

Use este formato ao decompor uma task do ClickUp:

```md
## Objetivo
<resultado observável>

## Escopo
<o que será alterado e o que fica fora>

## Dependências
- <subtask, decisão, arquivo ou acesso necessário>

## Critério de aceite
- <evidência objetiva de conclusão>

## Validação
- <teste, comando ou verificação manual proporcional ao risco>

## Bloqueios
- Nenhum, ou descreva o bloqueio sem mascará-lo.
```

Uma subtask deve ser pequena o bastante para ser implementada e validada sem misturar decisões independentes. Se não houver critério de aceite observável, retornar à análise da task principal antes de criar a subtask.
