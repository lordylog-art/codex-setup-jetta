# Idea Generation Patterns

Use this reference to widen the search space and force differentiated options.

## Divergence Methods

### 1. Extreme Contrast

Generate options at opposite poles:

- cheap vs premium
- playful vs serious
- invisible vs theatrical
- manual-feeling vs fully automated
- niche-first vs mass-first

### 2. Constraint Inversion

Reverse an assumed rule:

- what if it had no interface?
- what if it worked in 5 minutes?
- what if it required community participation?
- what if the business model were the product?

### 3. Borrowed Mechanics

Import mechanics from another domain:

- game loops
- concierge services
- marketplaces
- memberships
- collectables
- rituals
- diagnostics

### 4. Audience Shift

Keep the core problem, change who benefits first:

- beginner
- power user
- manager
- parent
- creator
- local business

### 5. Emotion-First Ideation

Design around the emotion to create:

- relief
- status
- momentum
- belonging
- curiosity
- control

### 6. Wedge Then Expand

Start with a narrow, compelling use case, then suggest the broader platform path.

## Remix Formula

Use:

`familiar thing + unexpected mechanic + clear user payoff`

Examples:

- CRM + voice memo workflow + faster follow-up
- study planner + streak rescue + lower guilt and better consistency
- local guide + scavenger hunt + more foot traffic for small shops

## Novelty Escalation Ladder

If the first batch feels generic, escalate in this order:

1. sharpen the audience
2. sharpen the pain
3. change the interaction model
4. change the economic model
5. combine with a distant domain
6. introduce a counterintuitive constraint

## Quality Check

Before keeping an idea, test:

- Is it materially different from the previous one?
- Can it be explained in one clean sentence?
- Is the value obvious to the target user?
- Does it create curiosity, urgency, or strategic advantage?

If not, improve it or remove it.
