# Output Recipes

Use this reference when the user would benefit from a response format tailored to the kind of ideation request.

## Product Ideas

For each option, include:

- name
- user pain
- core mechanism
- why now
- MVP test

## Content Or Campaign Ideas

For each option, include:

- angle
- hook
- format
- why it can spread
- production difficulty

## Naming Ideas

For each option, include:

- name
- tone
- signal it sends
- why it is memorable
- any ambiguity or risk

## Offer Or Business Model Ideas

For each option, include:

- offer concept
- target buyer
- pricing logic
- perceived value driver
- objection to solve

## Internal Process Ideas

For each option, include:

- bottleneck addressed
- new mechanism
- expected gain
- implementation difficulty
- first experiment
