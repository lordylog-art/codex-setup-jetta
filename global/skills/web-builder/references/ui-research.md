# UI Research

## When To Browse

Browse when the task involves:
- creating a new screen or design system
- refreshing a dated interface
- choosing layout, motion, or component direction
- finding current references for tables, dashboards, forms, command panels, timelines, or operational UIs

## Research Method

1. Identify the screen type and user goal.
2. Search for recent references from credible design sources, product examples, or official component docs.
3. Extract patterns, not copies:
   - information hierarchy
   - navigation model
   - density and spacing
   - feedback states
   - motion ideas
4. Implement an original UI adapted to the actual product constraints.

## Frontend Quality Checklist

- Desktop and mobile both work.
- Loading, empty, error, and success states exist.
- Forms have labels, help text when needed, and actionable validation.
- Tables and cards prioritize the operational decision, not decoration.
- Motion supports comprehension and never blocks interaction.
- Visual direction is coherent across typography, color, border radius, and elevation.
