Snapshot das skills locais enviado em 22/10/2026. Inclui skills próprias e de terceiros, inclusive Matt Pocock, conforme solicitado. As cópias instaladas no computador foram preservadas.

| Pasta | Origem |

As versões por contexto foram mantidas separadas, mesmo quando têm o mesmo nome. Recursos, scripts, testes e licenças presentes nas pastas acompanham cada skill. `installation-locks` preserva os registros de origem disponíveis; `manifest.json` registra SHA-256 de cada arquivo copiado.

Não inclui caches de plugins, sessões, credenciais, configuração do Codex, bancos, `node_modules` ou caches de Python. Referências a caminhos e documentos externos às pastas das skills continuam dependendo dos projetos e ferramentas correspondentes. Este snapshot não muda o instalador legado na pasta `scripts/` nem instala ou executa as skills automaticamente.
