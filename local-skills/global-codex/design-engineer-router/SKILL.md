# Design engineer router

Local Codex adaptation of julianromli/ai-skills. The original references an unavailable emil-* catalog. This router uses the public emilkowalski/skills catalog and installed companion skills; they are complementary, not claimed equivalents of the missing skills.

## Workflow

1. Identify the requested phase and material. Preserve the user's visual direction and repository rules.
2. Read the SKILL.md of one to three relevant skills below. Resolve sibling paths relative to this directory.
3. Apply their guidance within the authorized scope and use the host's actual tools.
4. Verify changed behavior and visuals proportionally. Report which skills were used and concrete validation limits.

## Completion

Review the changed UI against the requested design, keyboard/focus behavior, reduced motion and affected viewport sizes. Use existing project checks. Report out-of-scope findings without expanding the implementation. Deployment and external account operations retain their own authorization requirements.
